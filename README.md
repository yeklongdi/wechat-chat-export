# 微信聊天导出 Skill

## 功能

直接将 **Windows 微信 4.x** 本机保存的**群聊和好友聊天记录**导出为 **TXT、JSON**，供 Codex 等软件读取，保留发言人、时间、正文和引用。支持按群名、好友备注／昵称或会话 ID 选择，按时间范围或全部历史导出，**无需转发到文件传输助手**。

只涵盖当前电脑已有的记录；图片、语音、视频及附件保留类型和可解析描述，暂不导出文件本体。原有的文件传输助手导出和合并转发展开功能仍可使用。

## 怎么调用

保持电脑微信已登录，在安装了本 skill 的 Codex 会话中发送（将示例名称替换为实际群名和好友备注）：

```text
使用 $wechat-chat-export，直接导出“项目讨论群”和好友“张三”
最近 60 分钟的聊天记录，保存为 TXT 和 JSON。
```

需要全部记录时，把时间范围改为“本机保存的全部历史”；不确定名称时，可以先说“列出名称包含 XXX 的会话”。遇到重名会先列出候选供你选择，多个会话分别保存。也可以指定其他时间范围和保存位置。
