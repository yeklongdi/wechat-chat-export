# 微信聊天导出 Skill

## 功能

适用于 **Windows 微信 4.x**。将文件传输助手中的消息及合并转发记录导出为 **TXT、JSON**，供 Codex 等软件读取，保留原始发言人、时间、正文和引用。图片、视频及附件仅保留类型和描述。

## 怎么调用

1. 在需要整理的群聊或好友对话中选中消息，**合并转发到自己的文件传输助手**。不同群聊、好友的记录都可以通过这个流程处理。
2. 保持电脑微信已登录，在安装了本 skill 的 Codex 会话中发送：

```text
使用 $wechat-chat-export，导出文件传输助手最近 60 分钟的记录，
展开合并转发，保存为 TXT 和 JSON。
```

“最近 60 分钟”指消息转入文件传输助手的时间，原始对话可以来自更早日期。也可以在提示中指定其他时间范围和保存位置。
